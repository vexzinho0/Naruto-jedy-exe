# Co Launcher

Uma interface Android nativa, em Jetpack Compose, para organizar perfis de um launcher de Minecraft Java.

## Estado atual

O projeto fornece o painel inicial, seleção de perfil e estados de preparação para o jogo. Para iniciar uma instalação do Minecraft Java, um launcher precisa ainda integrar um runtime Java compatível, a autenticação Microsoft/Minecraft e os arquivos de jogo obtidos legalmente. O Co Launcher não inclui nem distribui arquivos do Minecraft.

## Abrir no Android Studio

1. Abra esta pasta no Android Studio Ladybug ou mais recente.
2. Aguarde a sincronização do Gradle.
3. Execute o módulo `app` em um dispositivo Android (API 26+).
